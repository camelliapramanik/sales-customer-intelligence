# Extracted model evidence

These files are generated by [export_portfolio_metadata.py](../../tools/export_portfolio_metadata.py) using PBIXRay 0.15.5. They make the report inspectable without Power BI Desktop.

| File | Contents |
| --- | --- |
| [schema.json](schema.json) | Core business table columns and decoded model types |
| [relationships.json](relationships.json) | Active relationship metadata from the model |
| [measures.json](measures.json) | All 55 original DAX expressions and extracted metadata |
| [report_pages.json](report_pages.json) | Page visibility, visual types, stored titles, and actual field bindings |
| [snapshot.json](snapshot.json) | Unfiltered imported-data aggregates and original PBIX SHA-256 |
| [data_checks.json](data_checks.json) | Key, dimension-match, date-continuity, and profit-rounding checks |

Stored visual titles can contain hidden or stale labels; the field bindings determine the actual data shown. The report guide describes bound fields rather than inferring them from a stored title.

The exporter does not execute SQL, evaluate DAX, or render the report. Decimal category/channel/territory aggregates may be represented as JSON strings to retain their source precision. Regeneration overwrites these exports, DAX/Measures.dax, and the Power Query M files; review handwritten documentation separately after changes.
